# BC-data
Auto-generated miscellaneous data extracted from BC, including as of the moment:

* `bc_data.assetVersion`: A record containing the BC version (starting from >R98) in which each asset was added.
* `bc_data.assetID`: A record with unique integer-based group & asset IDs.
* `bc_data.iconPaths`: A record with all image files in the BC `Icons/` directory. See the `bc_data.Icons` type for a union of all of its keys.
* `bc_data.audioPaths`: A record with all audio files in the BC `Audio/` directory. See the `bc_data.Audio` type for a union of all of its keys.
* `bc_data.backgroundPaths`: A record with all image files in the BC `Backgrounds/` directory. See the `bc_data.Backgrounds` type for a union of all of its keys.

# Installation
The package can be installed from npmjs as following: `npm install bc-data`.
